RadiVault Buyer UX v3 — Dense list redesign

v2 was too low-density and over-emphasized De-ID provenance to buyers. v3 absorbs Segmed Openda's dense table style while preserving v2's anti-Segmed signature (navy/teal, Pretendard, hospital badges, KCD-triple ontology). v2 는 정보 밀도가 낮았고 De-ID provenance 를 buyer 에게 과도 노출했습니다. v3 는 Segmed Openda 의 dense table 스타일을 흡수하되, v2 의 anti-Segmed 시각 시그니처(navy/teal, Pretendard, 병원 badge, KCD 트리플 ontology)는 보존합니다.
