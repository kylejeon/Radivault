## 1. 한 줄 제안

**귀원의 의료영상(DICOM) 데이터를 귀원 내부에서 완전 익명화한 뒤, 글로벌 의료 AI 시장에 합법적으로 공급하고 수익을 공유합니다.**

- 귀원이 얻는 것: 수익 공유, 데이터 주권 유지, 기술 부담 없는 Gateway 무상 제공, 글로벌 AI 산업 레퍼런스.
- 귀원이 해줘야 할 것: Gateway Agent 1대용 서버 제공, PACS DICOMweb 연동, 데이터 철회 프로세스 운영 동의.

상세는 이하 §4, §5.

## 2. 배경 — 왜 지금, 왜 한국인가

### 2.1 글로벌 의료 AI 데이터 시장

- 글로벌 의료영상 AI 시장: 2025년 기준 약 $1.65–2.5B 규모, 연평균 30% 이상 성장 (리서치 §2).
- 헬스케어 데이터 수익화 시장: 2024년 $0.92B → 2034년 $4.08B 예상 (CAGR 16%, 리서치 §2).
- 미국은 FDA 승인 AI 의료기기 500개 이상(2025)으로 데이터 수요가 폭증.

### 2.2 한국 의료영상 데이터의 차별점

- **PACS 보급률 세계 최고 수준**: 전국 9,000개 이상 의료기관, 445개 기관이 영상정보 전송 체계 완비 (리서치 §4).
- **OECD 최고 수준의 영상 촬영량**: 건강보험 단일체계 기반, CT/MRI 인구당 촬영 빈도 세계 상위 (리서치 §4).
- **글로벌 검증된 한국 AI 기업 생태계**: Lunit, VUNO, Coreline Soft, JLK 등이 FDA 인허가를 다수 획득하면서 **한국 임상 데이터의 품질이 이미 글로벌에서 검증**됨 (리서치 §4).
- **다양성 프리미엄**: 미국 AI 기업이 요구하는 인종·장비 다양성 요건에서 한국 데이터는 **희소 자산** 위치.

### 2.3 결과

한국은 "AI가 배포되는 시장"으로는 이미 자리 잡았지만 **"AI가 학습할 데이터가 합법적으로 공급되는 시장"** 으로는 아직 초기 단계입니다. RadiVault는 이 구조적 기회를 **병원·플랫폼·구매자 3자 모두에게 법적으로 안전한 방식**으로 연결합니다.

## 3. RadiVault 모델 — 3가지 핵심 포인트

### 3.1 병원 On-Premise (데이터는 병원에 잔존)

- Gateway Agent(Docker 컨테이너)가 귀원 전산망 내부에 설치됩니다.
- 원본 DICOM은 **귀원 PACS에 그대로** 남습니다.
- 중앙으로는 **완전 익명화된 사본**만 전송됩니다.
- 원본↔가명 UID 매핑 테이블은 **귀원 내부에만** 보관되며, 매핑 없이 중앙·해외에서는 역추적이 불가능하도록 설계되어 있습니다.

### 3.2 완전 익명화 (개인정보보호법 국외이전 규제 대응)

- **DICOM PS3.15 Annex E Basic Profile**(의료 영상 표준 익명화 규격) + RadiVault 추가 옵션 적용.
- PHI 태그 제거·대체, UID 가명화, 환자별 고정 날짜 오프셋, 번인 텍스트 자동 격리.
- 각 스터디 업로드 전 **자동 재검증(reverify)** 을 통해 PHI 잔존 여부 이중 확인.
- 개인정보보호법 제28조의8의 **국외이전 규제에 부합하도록 설계**되었으며, HIPAA Safe Harbor 기준과 정합되도록 구성되어 있습니다.
- 법무 자문 진행 중이며 파일럿 계약 단계에서 자문 요약을 공유합니다.

### 3.3 중앙 글로벌 브로커 (Zone 2·3)

- RadiVault 중앙(한국 리전 기본)은 익명화된 메타·영상을 통합 인덱싱합니다.
- 글로벌 구매자(AI 기업, 제약/바이오, 연구기관)는 중앙 포털을 통해 데이터를 조달합니다.
- 주문 확정 → 가명 UID 기반 전송 → 구매자 수령 → 7일 TTL 자동 삭제의 구조.
- 모든 접근·전송은 감사 로그로 불변 보존되며, 병원별 수익이 자동 정산됩니다.

## 4. 귀원이 얻는 것

### 4.1 수익 공유

- Tier별 수익 배분은 **30–45% 범위** 내에서 계약으로 확정됩니다.
- 3-Tier 구조 (리서치 §8):
  - Tier 1 (기본·자동 라벨): 병원 배분 25–30%
  - Tier 2 (강화·전문의 라벨): 병원 배분 35–45%
  - Tier 3 (프리미엄·세그멘테이션): 병원 배분 40–50%
- **파일럿 병원 전용 조건**: 최소보장금(MG)을 **연 ₩500–1,000만 범위**에서 제공 (리서치 §11 근거). 정확한 금액은 귀원 데이터 규모·모달리티에 따라 계약서에서 확정.
- 수익 정산은 **월 단위 자동 투명 대시보드**로 실시간 확인 가능(Phase 2 구매자 포털 GA 시점).

### 4.2 데이터 주권 유지

- 원본 DICOM은 귀원 PACS에 잔존. 플랫폼이 원본을 보관하지 않습니다.
- 귀원이 RadiVault 참여를 중단해도 **귀원의 PACS 데이터에는 어떠한 변화도 없습니다**.
- 철회 요청 프로세스를 계약에 명시(상세 §7).

### 4.3 기술 부담 제로

- Gateway Agent는 **RadiVault가 무상 제공**합니다.
- 설치·초기 구성은 RadiVault SRE와 귀원 전산실의 공동 작업(30–60분 소요, 별도 온보딩 가이드 제공).
- 운영 중 기술 지원·보안 업데이트·소프트웨어 유지보수는 RadiVault 책임.
- PACS 교체·수정·추가 라이선스 구매 **불필요**.

### 4.4 레퍼런스 가치

- 한국 내 초기 파일럿 참여 병원으로서 글로벌 의료 AI 생태계 레퍼런스 확보.
- 공동 연구·공저 논문·국제 학회 발표 등 학술적 협력 기회 병행 논의 가능.

## 6. 컴플라이언스·법적 안전

### 6.1 한국 개인정보보호법

- **제28조의8**(개인정보 국외이전 제한): 완전 익명정보는 개인정보보호법 적용 대상에서 제외되어 국외이전 규제를 받지 않습니다 (리서치 §5).
- RadiVault는 **완전 익명정보만 중앙·국외로 전송**되도록 기술·절차 양면에서 설계되어 있습니다:
  - Gateway Agent가 병원 내부에서 Annex E Basic Profile + 추가 옵션 적용.
  - 업로드 전 자동 재검증으로 PHI 잔존 여부 이중 확인.
  - 중앙 서버는 `anonymization_flag != "fully_anonymized"`인 데이터 수신을 거부.
- 개인정보보호법상 "완전 익명정보" 성립은 **법무 자문 진행 중**이며, 자문 결과는 파일럿 계약 체결 단계에서 공유합니다.

### 6.2 HIPAA Safe Harbor

- 미국 구매자 대상 판매 시 HIPAA Safe Harbor 18 식별자 기준 충족을 목표로 설계되었습니다.
- Annex E Basic Profile + RadiVault 추가 옵션이 Safe Harbor 항목을 포괄하도록 구성됩니다.

### 6.3 인증 계획

| 단계 | 시기 | 상태 |
|------|------|------|
| 자체 보안 정책 + 파트너 인증 활용 | Phase 1 (현재) | 운영 중 |
| SOC 2 Type I | Phase 2 | **준비 중** (목표 시점 TBD) |
| SOC 2 Type II + ISO 27001 | Phase 3 | **준비 중** (목표 시점 TBD) |

v0.1 단계에서는 **인증 보유 주장을 하지 않습니다**. 인증 취득 시 공식 고지합니다.

### 6.4 감사 추적

- 모든 데이터 접근·변환·전송은 불변 감사 로그로 보존됩니다(최소 5년).
- 병원별 자기 데이터 접근 이력을 언제든 열람할 수 있습니다.
- 감사 로그는 hash-chain 구조로 단독 변조 탐지가 가능합니다.

### 6.5 내부 IRB·윤리 검토

- RadiVault는 귀원 IRB 검토 절차를 지원합니다.
- 필요 시 IRB 제출용 프로토콜 서식·기술 설명 자료를 제공합니다.

### 6.6 데이터 오너십

- 데이터 오너십은 **귀원에 유지**됩니다. RadiVault는 사용권(라이선스)만 확보하는 모델입니다.
- 모든 구매 계약서에 귀원의 철회권·수익 청구권이 명시됩니다.

## 8. FAQ — 경영진 관점 5개

### Q1. 법적 리스크가 정말 없습니까?

완전 익명정보로의 변환은 **병원 내부에서** 수행되며, 중앙은 익명화 완료 데이터만 수신합니다. 개인정보보호법 제28조의8의 국외이전 제한은 완전 익명정보에는 적용되지 않는다는 것이 업계 법무법인의 공통 해석입니다 (리서치 §5). 다만 **최종 법적 판단은 법무 자문 결과에 따라 확정**되며, 현재 자문이 진행 중입니다. 자문 요약은 파일럿 계약 단계에서 귀원과 공유됩니다.

### Q2. 환자 동의를 다시 받아야 하나요?

완전 익명정보는 개인정보가 아니므로 개인정보보호법상 동의 의무 대상에서 제외됩니다. 다만 병원 자체의 내부 정책·IRB 규정에 따라 추가 검토가 필요할 수 있으며, RadiVault는 IRB 제출 자료를 지원합니다. 최종 판단은 귀원 DPO·IRB가 수행합니다.

### Q3. 수익은 언제, 어떻게 받게 됩니까?

Phase 2 구매자 포털 GA 이후 구매가 발생하는 시점부터 월 단위 자동 정산됩니다. Phase 1 파일럿 단계에서는 **최소보장금(MG)** 을 계약서 명시 주기(분기 또는 반기)에 따라 선제 지급하는 형태로 제공 가능합니다. 구체 금액·주기는 계약서에서 확정합니다.

### Q4. 중간에 해지할 수 있나요?

네. 계약서에 명시된 사전 통지 기간 후 일방 해지가 가능합니다. 해지 시 Gateway Agent 중단, 중앙 토큰 즉시 revoke, 원본 PACS 데이터는 귀원에 그대로 잔존. 이미 중앙에 수령된 익명화 사본의 처리 방침은 계약서 조항을 따릅니다.

### Q5. 문제가 생기면 책임 소재는 어떻게 됩니까?

계약서에 책임 분담 조항을 명시합니다:
- **귀원 책임 범위**: PACS 자체 데이터의 정확성, 병원 내부 운영, DPO 승인 절차.
- **RadiVault 책임 범위**: Gateway Agent의 정상 동작, 익명화 기술 무결성, 중앙 보안, 감사 로그 보존, 구매자 계약 관리.
- **공동 대응**: 규제 당국 문의, 감사 요청, 보안 사고 대응.

구체 책임 한도·보험 커버리지는 계약서 조항을 따릅니다.
