# K-MedData 리서치 요약

> Phase 1 리서치 산출물. 전체 리서치 문서(첨부)의 핵심을 정리한 프로젝트 내부 사본입니다. PRD·아키텍처 작성 시의 근거 문서이며, 이후 변경이 필요하면 이 문서가 아닌 `docs/research/`에 신규 파일로 증보합니다.

## 1. 사업 개요

- **한 줄 정의**: 한국 병원의 의료영상(DICOM)을 수집·익명화하여 글로벌(주로 미국) AI 기업에 판매하는 B2B 데이터 브로커 플랫폼.
- **피벗 히스토리**: 초기 C2B2B(환자 개인이 직접 영상 업로드) 구상은 **폐기**. 사유 — 개인정보보호법 국외이전 제한, 가격 책정/품질 검증 비용, 환자 모집 난이도.
- **현재 모델**: 병원 단위 B2B 공급.
- **프로젝트명**: RadiVault (코드네임 K-MedData).

## 2. 시장

- 글로벌 의료영상 AI 시장: 2025년 기준 ~$1.65–2.5B, CAGR 30%+
- 헬스케어 데이터 수익화(monetization) 시장: 2024년 $0.92B → 2034년 $4.08B (CAGR 16%)
- 주요 지역
  - **북미(미국)**: 전체의 40–45%. FDA 500+개 AI 의료기기 승인(2025), 방사선과 인력 부족 → AI 수요 급증.
  - **유럽**: 2위 시장, 유방암 스크리닝 중심.
  - **아시아태평양**: CAGR 30.8%로 가장 빠른 성장이지만 "배포" 시장이지 "데이터 구매" 시장은 아님.
- 구매자 유형: (1) AI/의료기기 기업, (2) 제약/바이오, (3) 학계/연구기관.

## 3. 경쟁사

### Segmed (Palo Alto, $20.3M Series A / 2024)
- 5개 대륙 2,000+ 병원 파트너, 1억+ 스터디.
- Revenue share 계약 → 비식별화·표준화 → 프로젝트별 판매.
- 자체 비식별화 툴 "Incognito", SOC 2 Type II + ISO 27001 + HIPAA.
- 핵심 인사이트: Advocate Health(67개 병원)가 Series A 투자자 = **데이터 공급자가 동시에 주주**인 모델.

### Gradient Health (Durham, NC)
- 65M+ 영상, 셀프서비스 플랫폼 "Atlas" (48시간 내 전달).
- Python SDK + REST API, Google Cloud Marketplace 입점(2025).
- CEO 장기 비전: 환자가 영상 검사비 할인 대가로 데이터 제공(미구현).

### 공통점
- 모두 **병원 단위 B2B 파트너십**. 환자 직접 참여 모델은 없음.
- 데이터 소유권은 병원 유지, 플랫폼은 사용권만 확보.
- Revenue share 비공개. 업계 추정 공급자 몫 15–40%.

## 4. 왜 한국인가

1. **PACS 보급률 세계 최고**: 전국 9,000+ 의료기관, 445개 기관 영상정보 전송 가능.
2. **OECD 최고 영상 촬영량**: 건강보험 단일체계, CT/MRI 인구당 촬영 빈도 세계 상위.
3. **글로벌 검증 AI 기업**: Lunit($60M 매출, 2025), VUNO, Coreline Soft, JLK 다수 FDA 인허가 → 한국 데이터 품질 글로벌 인정.
4. **영상 다양성 프리미엄**: 미국 AI 기업이 요구하는 인종·장비 다양성 데이터. 한국 데이터는 희소 자산.
5. **한국 의료 AI 시장**: 2023 $0.37B → 2030 $6.67B (CAGR 50.8%).

## 5. 법적 구조 및 규제

### 한국 (수집·국외이전)
- **개인정보보호법 제28조의8**: 개인정보 국외이전 원칙적 금지. 가명정보도 규제 대상.
- **핵심 우회 전략**: **완전 익명정보**(시간·비용·기술 합리적으로 고려할 때 재식별 불가)는 개인정보보호법 적용 대상에서 제외 → 국외이전 규제 미적용.
- **의료법·생명윤리법 중첩**: 다기관 연구, 해외 파트너와의 동의 상충, 활용 범위 해석 등 법적 리스크 존재.
- **보건의료데이터 활용 가이드라인 (2024.12 개정)**: 데이터 유형별 가명처리 방식 제시.
- **업계 컨센서스**: "원본 데이터의 해외 전송은 개인정보보호법상 거의 불가능" (법무법인 공통).

### 미국 (판매)
- **HIPAA**: 완전 익명화된 데이터는 PHI 비해당. BAA(Business Associate Agreement) 체결 권장.
- **SOC 2 Type II**: 엔터프라이즈 구매자 83%가 요구. 비용 $25K–$50K, 기간 6–12개월. Vanta/Drata로 50% 단축 가능.
- **ISO 27001**: SOC 2와 70% 중복. 동시 취득 시 추가비용 30–40%만.
- **권장 법인 구조**: 한국 법인(수집·익명화) + 미국 Delaware 법인(판매·고객 관리) 이중 구조.

## 6. 플랫폼 아키텍처 — Model 3 Hybrid

### 왜 Hybrid인가
- **Model 1 (전량 중앙집중, Segmed 방식)**: 응답 빠름 / 스토리지 비용 폭발 + 한국법 국외이전 리스크.
- **Model 2 (연합형)**: 데이터 병원에 잔존, 법적 안전 / 응답 느림.
- **Model 3 (Hybrid)** ← 채택: 메타데이터만 실시간 동기화 + 영상 원본은 구매 확정 후 온디맨드 전송. 초기 자본 최소, 법적 리스크 최소.

### 3-Zone 구조
1. **Zone 1 — 병원 내부 (On-Premise)**: Gateway Agent(Docker), De-ID Engine, PACS Connector(DICOM C-FIND/C-MOVE, DICOMweb WADO-RS/QIDO-RS), Staging Storage.
2. **Zone 2 — 중앙 클라우드**: Metadata Index DB, NLP Label Engine, Thumbnail Cache + CDN, Hot Storage(인기 데이터만), Order Orchestrator, Billing & Revenue Share.
3. **Zone 3 — 구매자 인터페이스**: Web Portal(코호트 검색, DICOM 웹 뷰어), Developer API/SDK, Download Manager(S3 presigned URL).

### 데이터 플로우
- **Flow A (상시)**: PACS → Gateway → 메타+판독문(익명화) → 중앙 인덱스 + NLP 라벨링.
- **Flow B (주문 시)**: 구매 확정 → Orchestrator → Gateway 명령 → De-ID → 클라우드 임시 영역 → 구매자 다운로드 → 7일 TTL 자동 삭제.
- **Flow C (선제적)**: 인기 코호트 자동 식별 → 사전 익명화 → Hot Storage 상시 보관.

## 7. 라벨링 파이프라인

1. **Level 1 — NLP 자동 라벨**: 판독문 → LLM 진단명 추출. ($3–8/건)
2. **Level 2 — 이미지 분류**: 영상의학과 전문의 이진 분류. ($15–40/건)
3. **Level 3 — 바운딩 박스**: 병변 위치.
4. **Level 4 — 세그멘테이션**: 픽셀 단위 경계. FDA 인허가용. ($50–150/건)

도구 옵션: V7 Darwin, Encord, MONAI Label(무료), Label Studio Enterprise, 자체 개발.

## 8. 수익 모델 (3-Tier)

| Tier | 데이터 | 가격/건 | 병원 배분 | 플랫폼 |
|------|--------|--------|----------|--------|
| 1 | 기본 (자동 라벨) | $3–8 | 25–30% | 70–75% |
| 2 | 강화 (전문의 라벨) | $15–40 | 35–45% | 55–65% |
| 3 | 프리미엄 (세그+주석) | $50–150 | 40–50% | 50–60% |

**판매 패키지**: 소규모 $1K–5K / 중규모 $5K–30K / 대규모 FDA용 $50K–200K+ / 구독 월 $2K–10K.

## 9. 익명화 기술 난이도

- **쉬움**: DICOM 메타데이터 PHI 제거 (pydicom), 3D defacing (pydeface).
- **중간**: 번인 텍스트 OCR 마스킹, 한국어 판독문 NER.
- **어려움**: 얼굴 CT(부비동·치과), 희귀질환(소량 자체가 식별자), k-익명성 검증.

**대응**: Tier 1 자동 / Tier 2 반자동 + 사람 QA / Tier 3 정책적(제외·문서화). 초기에 개인정보보호 전문 변호사 자문 필수.

## 10. 로드맵

- **Phase 1 (0–6개월)**: 병원 1–2곳 파일럿(배분 40%+최소보장금), Gateway Agent + De-ID MVP, Segmed/Gradient의 한국 공급 파트너십 탐색.
- **Phase 2 (6–18개월)**: 병원 10곳+, 자체 검색 포털 MVP, SOC 2 Type I→II, 척추 특화 데이터셋(Kyle 도메인 활용).
- **Phase 3 (18–36개월)**: Delaware 법인, SOC 2 Type II + ISO 27001, FDA용 프리미엄 데이터셋, 시리즈 A.

## 11. 재무 추정

- **매출**: Y1 $80K / Y2 $450K / Y3 $1.5M. Gross margin 60–70%.
- **초기 투자**: 게이트웨이 개발 ₩3,000만 + 클라우드 ₩700만/년 + SOC 2/ISO ₩5,000–8,000만 + 인건비(3명) ₩2.5억/년.

## 12. 핵심 리스크

| 리스크 | 심각도 | 대응 |
|--------|--------|------|
| 한국 규제 변동 | 높음 | 완전 익명정보 전략 + 초기 법률 자문 |
| 병원 온보딩 난이도 | 중간 | 파격 조건 파일럿 → 레퍼런스 확보 |
| PACS 연동 복잡성 | 중간 | DICOM 표준 프로토콜 활용, 벤더 비의존 |
| 재식별화 위험 | 중간 | 다층 익명화 + k-익명성 + 정책 제외 |
| 경쟁사 한국 진입 | 낮음 | 선점 + 게이트웨이 기반 병원 lock-in |
| 인증 취득 지연 | 낮음 | Phase 1은 파트너 인증 활용 |
