## §2. 데이터 플로우 (Model 3 Hybrid 3-Zone)

변호사가 국외이전 규제 해석 시 참조할 필수 사실관계.

```
┌─────────────────┐   HTTPS outbound only   ┌────────────────────┐   Presigned URL   ┌────────────┐
│ Zone 1: 병원     │ ───────────────────────▶│ Zone 2: 중앙 클라우드│ ─────────────────▶│ Zone 3:     │
│ (한국, On-prem) │  메타만 상시 / 영상은   │ (서울 리전, 운영자 │ 24h TTL, SHA-256  │ 글로벌 구매자│
│                 │  주문 시점에만 pull      │  관리)              │ 체크섬            │ (AI 기업 등) │
│ · PACS          │                         │                     │                   │              │
│ · Gateway Agent │                         │ · Metadata Index    │                   │ · Buyer API  │
│ · De-ID Engine  │                         │ · Object Storage    │                   │   Portal     │
│ · Staging TTL   │                         │ · Audit (WORM)      │                   │              │
└─────────────────┘                         └────────────────────┘                   └────────────┘
      │                                              ↑
      └── 매핑 테이블(원본↔가명 UID) 병원 내부에만 ──┘
              중앙·해외로 **절대 송출되지 않음**
```

### §2.1 익명화 수행 위치 (중요)

- **익명화는 Zone 1(병원 내부)에서 전량 수행**된다.
- DICOM PS3.15 Annex E Basic Profile 기반 18개 PHI 태그 제거 + UID 재생성 +
  날짜 시프트 + 번인 텍스트 OCR 마스킹 + 얼굴 CT/MRI defacing.
- 국외·중앙으로 나가기 전에 **자동 PHI 스캐너 재검증** → 통과한 건만 전송.

### §2.2 익명화 후의 정보 유형 주장

- 개인정보보호법 §2조 1항 "개인정보" 정의를 벗어난 **익명정보**로
  취급한다는 것이 우리 내부 설계 전제이다.
- 해당 주장의 법적 타당성을 **확증한 외부 의견은 아직 없다**.
