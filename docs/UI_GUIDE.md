## 1. 범위

RadiVault는 세 가지 UI 표면을 갖습니다. 각각의 상세 디자인 명세는 `docs/specs/design-spec-*.md`에 별도 작성합니다.

1. **구매자 포털 (Zone 3)** — 글로벌 AI 기업·연구자 대상. 영어 우선, 한국어 보조.
2. **병원 관리 콘솔 (Zone 1/2)** — 병원 담당자용 수익 대시보드, 데이터 현황, 철회 요청.
3. **운영자 콘솔 (Internal)** — RadiVault 팀 전용. 라벨링 QA, 주문 관리, 감사.

## 2. 디자인 원칙 (착수 전 잠정안)

- **신뢰 우선**: 의료 데이터 플랫폼 — 톤은 신중·전문·절제. 화려함 지양.
- **데이터 밀도**: 연구자·AI 엔지니어가 주 사용자 → 정보 밀도 높게, 불필요한 장식 없이.
- **감사 가능성 시각화**: 익명화 상태·감사 로그를 UI에서 항상 확인 가능하도록.
- **이중 언어**: i18n 설계. ko/en 전환 필수.
- **접근성**: WCAG 2.1 AA 준수 목표.
