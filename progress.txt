- _template/pipeline-guide.md §8 추가 — 에이전트 정의 위치 링크

### 유기적 협업 설계
Claude 서브에이전트는 서로를 직접 호출할 수 없으므로, 메인 Claude 세션이 오케스트레이터 역할. 각 에이전트는:
1. 선행 산출물 필수 읽기 (없으면 이전 단계 요청 리턴)
2. feature-slug 일관성 유지 (dev-spec ↔ design-spec ↔ qa-report)
3. 표준 핸드오프 블록(NEXT_STEP) 출력 — 메인이 다음 에이전트 호출

### 도구 권한 (최소 권한 원칙)
- researcher: Read/Write/Grep/Glob/WebSearch/WebFetch/Bash(find용)
- planner, designer: Read/Write/Grep/Glob (순수 스펙 작성)
- developer: Read/Write/Edit/Bash/Grep/Glob (풀 코딩)
- qa: Read/Bash/Grep/Glob/Write (검수만, 코드 수정 금지)
- marketer: Read/Write/WebSearch/WebFetch/Grep/Glob
- 전원: main 브랜치 접근·git push·파일 삭제 금지 룰 시스템 프롬프트에 명시

### 어디까지 됐나
- 부트스트랩(문서 + 에이전트) 완료. 이제 Phase 2 "Planning" 실제 착수 가능.
- 모든 에이전트 정의가 claude 브랜치 위에 있으며 main은 bootstrap 커밋 1개만 존재.
